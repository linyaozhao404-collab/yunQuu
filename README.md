# yunQuu

这是一个面向学生项目的 Kahoot 风格实时课堂答题平台升级版。它在第一版基础上加入图片题、音频题、视频题、判断题、多选题、排序题、题库搜索、教师/学生账号、游戏历史、成绩统计、更丰富的角色、道具系统、音效、背景音乐、开始动画、答题正确/错误反馈、Socket.IO 重连基础能力、房间自动过期、管理员后台，以及可选 HTTPS。

## 运行

需要 Node.js 18+。

```bash
npm install
npm start
```

浏览器：

- 首页：http://localhost:3000/
- 教师：http://localhost:3000/teacher/
- 学生：http://localhost:3000/student/
- 管理员：http://localhost:3000/admin/

## 示例账号

第一次运行会自动生成 `data.json`：

- 教师：`teacher` / `teacher123`
- 学生：`student` / `student123`
- 管理员：`admin` / `admin123`

建议课程项目完成后立刻修改示例密码，并在正式部署时换成真正的数据库和安全会话方案。

## 已实现功能

1. 图片题：题目支持图片 URL。
2. 音频题：题目支持音频 URL。
3. 视频题：题目支持视频 URL。
4. 判断题。
5. 多选题。
6. 排序题：学生使用上下按钮调整顺序。
7. 题库搜索：按标题、描述、标签搜索。
8. 教师账号：登录、注册、题库、创建游戏。
9. 学生账号：登录、注册、保存历史/统计归属。
10. 游戏历史：教师查看历史局。
11. 成绩统计：教师和学生分别统计。
12. 20 个角色样式。
13. 道具：×2 计分、+3 秒、答错保底。
14. 音效：浏览器 Web Audio 生成。
15. 背景音乐：浏览器 Web Audio 生成简单循环旋律。
16. 游戏开始与答题反馈动画：倒计时/庆祝/错误反馈。
17. 断线重连：Socket.IO 自动恢复连接；正式版还应增加断点续答/状态恢复策略。
18. 房间自动过期：默认 2 小时无活动后清理。
19. 管理员后台：用户、教师、学生、题库、历史场次、活动房间统计。
20. HTTPS：当 `SSL_KEY` 和 `SSL_CERT` 环境变量指向有效证书时，服务器会自动启用 HTTPS。

## HTTPS 示例

macOS/Linux：

```bash
export SSL_KEY=/absolute/path/fullchain/key.pem
export SSL_CERT=/absolute/path/fullchain/cert.pem
npm start
```

服务器会根据证书是否存在自动切换 `https://localhost:3000`。真实网站还需要域名、反向代理 and 有效证书。

## 局域网测试

启动服务器后，在运行服务器的电脑执行 `ifconfig`，找到类似 `192.168.1.20` 的局域网地址。手机和电脑连接同一个 Wi-Fi 后访问：

```text
http://192.168.1.20:3000/student/
```

教师电脑打开：

```text
http://192.168.1.20:3000/teacher/
```

如果电脑防火墙拦截 Node.js，需要允许局域网入站连接。

## 当前原型与正式商业版的差距

本版本用 `data.json` 做持久化，适合课程项目、原型和局域网演示。正式上线建议替换为 PostgreSQL/MySQL + Redis，使用安全会话与 CSRF 防护，图片/音频/视频进入对象存储，加入 CDN、日志、监控、限流、资源清理、权限分层、真正的上传接口和更完整的断线恢复策略。

## 局域网多人游戏（老师电脑 + 手机/平板）

本版本服务器默认监听 `0.0.0.0`，允许同一局域网中的其他设备访问。服务器启动后，终端会自动打印类似：

```text
LAN access: http://192.168.1.20:3000
```

老师电脑打开：

```text
http://localhost:3000/teacher/
```

学生手机/平板必须打开老师电脑的局域网地址：

```text
http://192.168.1.20:3000/student/
```

注意：

1. 老师电脑和所有学生设备必须连接同一个 Wi-Fi / 同一个局域网。
2. 不要让学生访问 `localhost`，因为手机上的 `localhost` 指的是手机自己。
3. macOS 第一次运行 Node.js 时，如果系统询问是否允许网络连接，请允许。
4. 如果浏览器打不开，检查 macOS“系统设置 → 网络 → 防火墙”是否阻止 Node。也可以临时关闭防火墙测试。
5. 如果学校 Wi-Fi 开启了“客户端隔离 / AP Isolation”，同一 Wi-Fi 的设备也可能互相无法访问，此时需要换成允许设备互通的网络或用一个自己的路由器/热点。

也可以手动指定：

```bash
HOST=0.0.0.0 PORT=3000 npm start
```

## V3：无 AI 文稿导入
教师端新增“文稿导入”选项。无需 AI/API，使用本地规则解析：
- TXT / MD：识别“1.题目 + A-D + 答案 + 类型 + 时间”
- DOCX：提取 Word 文本后按同样规则解析
- CSV / TSV：支持题目、A、B、C、D、答案、时间、题型列
- XLSX / XLS：读取第一个工作表并按上述列名转换

推荐文稿格式：

1. 中国最长的河流是哪一条？
A. 黄河
B. 长江
C. 珠江
D. 黑龙江
答案：B
类型：单选题
时间：15秒

2. 下列哪些属于中国传统节日？
A. 春节
B. 万圣节
C. 中秋节
D. 感恩节
答案：AC
类型：多选题

导入后会先显示预览、题型、选项和识别出的答案，确认后才写入题库。
